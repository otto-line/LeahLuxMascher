## Schema Files (in `/sanity/schemaTypes/`)

### `project.ts`
Defines the Project document type with fields:
- `title` - Project name
- `slug` - URL-friendly identifier
- `year` - Year created ('26, '25, '24)
- `description` - Short description
- `fullDescription` - Detailed description with formatting
- `images` - Array of images (Sanity or local)
  - Can choose source: "sanity" or "local"
  - Sanity: Upload image directly
  - Local: Link to file path like `Images/FOREVER-LOVE/FL1.jpg`
- `hoverImage` - Menu preview image path
- `gridColumns` - Layout columns (2 or 3)
- `published` - Toggle visibility

### `cvItem.ts`
Defines CV Entry document type with fields:
- `title` - Event/exhibition name
- `year` - Year (number)
- `description` - Event details
- `dates` - Date range
- `location` - Venue/city

### `siteSettings.ts`
Defines Site Settings document for global customization:
- `colors` - Brand colors (red, text, background, accent)
- `fonts` - Font sizes (body, heading, menu)
- `spacing` - Gaps and padding
- `grid` - Image grid columns (desktop and mobile)
- `aboutContent` - Formatted about text

### `index.ts`
- Exports all three schema types to Sanity

## Build & Generation Scripts

### `scripts/generate.js`
Main generation script that:
1. Fetches all published projects from Sanity
2. Fetches all CV items from Sanity
3. Fetches site settings from Sanity
4. Generates `menu.json` with projects list
5. Generates `cv.json` with CV items
6. Generates `theme.css` with customized colors/fonts/spacing
7. Generates individual `.html` files for each project

**Usage:**
```bash
npm run generate
```

**Creates/Updates:**
- `menu.json` - Project list (used by index.html)
- `cv.json` - CV entries (used by cv.html)
- `theme.css` - Customized styles
- `[slug].html` - Individual project pages (e.g., studio.html, eavesdrop.html)

## Quick Start Checklist

After Node.js installation:

```bash
# 1. Copy env template
cp .env.example .env

# 2. Add your Sanity API token to .env
# Get from: https://manage.sanity.io/ → API → Tokens

# 3. Install dependencies
npm install

# 4. Start Sanity Studio
npm run dev
```

Then open http://localhost:3333 to manage content.
