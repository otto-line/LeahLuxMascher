================================================================================
                         NEXT STEPS
================================================================================

STEP 1: INSTALL NODE.JS
   - Download: https://nodejs.org/
   - Choose LTS version
   - Verify: open terminal, run: node --version

STEP 2: GET SANITY API TOKEN
   - Go to: https://manage.sanity.io/
   - Select project: ssrah1z8
   - API → Tokens → Add Token
   - Name: "Website Generator", set to Editor
   - Copy the token

STEP 3: CREATE .ENV FILE
   - In project directory, run:
     cp .env.example .env
   - Open .env with text editor
   - Paste your API token as SANITY_API_TOKEN

STEP 4: INITIALIZE SANITY STUDIO
   - In terminal, run:
     npm create sanity@latest -- --project ssrah1z8 --dataset production --template clean
   - Answer Yes for TypeScript
   - Let it install dependencies

STEP 5: MOVE SCHEMA FILES
   - The command above creates a /sanity directory
   - I've already created project.ts, cvItem.ts, siteSettings.ts
   - Move them to: /sanity/schemaTypes/
   - Update /sanity/schemaTypes/index.ts to import all three

STEP 6: START SANITY STUDIO
   - Run: npm run dev
   - Opens at http://localhost:3333
   - Create Site Settings document first
   - Then add Projects and CV items

STEP 7: GENERATE STATIC FILES
   - After adding content to Sanity:
   - Run: npm run generate
   - Creates/updates menu.json, cv.json, theme.css, *.html

STEP 8: TEST & DEPLOY
   - Test locally (check menu.json and cv.json load correctly)
   - Commit changes: git add . && git commit -m "Add Sanity integration"
   - Push: git push
   - GitHub Pages auto-deploys
